## Recent

### TheAIAtlas

*Jul 2026 – Present*

It's very hard to know what's going on in AI, because it's scattered through so many places: newsletters, YouTube videos, talks, universities, Twitter. So I built one place for it: models, benchmarks, papers, news, hardware, and software. Agents keep it up to date using a self-hosted, open-source LLM.

*Jul 2026*

I wanted to explore what goes inside LangChain, LangGraph, Google ADK, and the OpenAI and Anthropic software development kits (SDKs), so I implemented a mini version to learn how multi-agents work inside. You can swap model providers without changing your code.


## Older

### IOTA Tangle in IoT

*May 2021*

My Master's capstone: blockchain has high computation and scalability issues in the Internet of Things (IoT), so I proposed a model using the IOTA Tangle for devices to combine their services, and simulated it in a smart home: low computation and storage, with a little broadcast overhead.

### [Packet Analyzer](https://github.com/sudhir13s/packetanalyzer)

*May 2020*

For my computer networks course at RIT, I built a command-line tool that reads a binary dump of a packet and takes it apart, layer by layer: Ethernet, then IPv4, then ICMP, TCP, or UDP, printing the details of each.

### [Lunar Rover](https://github.com/sudhir13s/RIP-version2)

*Oct 2019 – May 2020*

For my networking course at RIT, I wrote Routing Information Protocol (RIP) v2 and my own reliable data transfer protocol from scratch, then sent files from one router to another with them. The idea was rovers (routers) sending observation data to a lander (hub) that transmits it back to Earth.

### [Classifying similar languages](https://github.com/sudhir13s/NLP-Term-project)

*May 2019*

The capstone project for the natural language processing (NLP) course at RIT on telling very similar languages apart, using classic machine learning (Naive Bayes and a linear support vector machine). I used character and word n-grams as features and reached 88% accuracy.

### DigitalOPD
